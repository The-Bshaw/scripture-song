# V3.5.2 UI adjustments
- Removed the explanatory paragraph under Songs at The Well.
- Themes beneath songs render as minimal underlined text links, retaining click-to-search.
- Added a compact, on-demand Spotify embedded player in cards with valid Spotify *track* URLs.
- Only one player remains open at a time. Close unloads the iframe, stopping audio.
- Songs without a Spotify track link do not show a player.
- Spotify controls whether an embed plays a short preview or requires listener login.
- Retains all existing song data, search matching and Google Sheets integration.
